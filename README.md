# Nextra AI | نكسترا — دليل الانطلاقة النظيفة (من الصفر بالكامل)

مشروع دردشة ذكاء اصطناعي مجاني بالكامل، جاهز للنشر على Vercel. هذا الدليل يفترض إنك بادئ بمستودع GitHub جديد ومشروع Vercel جديد تماماً — بدون أي علاقة بأي مشروع قديم.

---

## الخطوة 1: أنشئ مستودع GitHub جديد

1. روح لـ 🔗 **https://github.com/new**
2. اسم المستودع: `nextra-ai` (أو أي اسم تحب)
3. اختر **Public** أو **Private** (مايهم)
4. **لا تفعّل** "Add a README file" (عشان نرفع ملفاتنا مباشرة)
5. اضغط **Create repository**

## الخطوة 2: ارفع ملفات المشروع

بصفحة المستودع الجديد الفاضية:
1. اضغط **uploading an existing file** (رابط بمنتصف الصفحة)
2. اسحب **كل الملفات** اللي بهذي الحزمة **ما عدا** `chat.js` و `transcribe.js` (هذولا خاص لهم خطوة منفصلة تحت)
3. اضغط **Commit changes**
4. بعدها: اضغط **Add file → Create new file** → بمربع الاسم اكتب بالضبط `api/chat.js` (كتابة `api/` بالاسم تنشئ المجلد تلقائياً) → افتح ملف `chat.js` من الحزمة بأي محرر نصوص، انسخ محتواه كامل، والصقه → **Commit new file**
5. كرر نفس الشي لملف `api/transcribe.js`

النتيجة النهائية على GitHub لازم تكون:
```
nextra-ai/
├── index.html
├── manifest.json
├── sw.js
├── vercel.json
├── nextra-logo.png
├── nextra-mark.png
├── icon-192.png
├── icon-512.png
├── package.json
└── api/
    ├── chat.js
    └── transcribe.js
```

## الخطوة 3: احصل على مفاتيح API المجانية (روابط مباشرة)

### 1) مفتاح Groq (أساسي — النموذج الأسرع، مجاني)
🔗 **https://console.groq.com/keys**
- سجّل دخول (بريد إلكتروني أو Google)
- اضغط **Create API Key** → سمّه أي اسم → انسخ المفتاح فوراً (يبدأ بـ `gsk_...`) — ما يظهر لك مرة ثانية

### 2) مفتاح NVIDIA NIM (احتياطي — نماذج متعددة، مجاني)
🔗 **https://build.nvidia.com**
- سجّل دخول → من أي صفحة نموذج، دوّر على **Get API Key** أو **API** بأعلى الصفحة
- انسخ المفتاح (يبدأ بـ `nvapi-...`)

### 3) و4) مفاتيح Upstash Redis (لحد الصور المجانية بالساعة، مجاني)
🔗 **https://console.upstash.com**
- سجّل دخول بجوجل → **Create Database** → اختر اسم ومنطقة قريبة → **Create**
- بصفحة القاعدة، تحت قسم **REST API**، اضغط أيقونة 👁️ لكشف التوكن، وانسخ:
  - `UPSTASH_REDIS_REST_URL`
  - `UPSTASH_REDIS_REST_TOKEN`

### 5) مفتاح Gemini (اختياري — لخيار "جودة عالية" المدفوع بتوليد الصور)
🔗 **https://aistudio.google.com/apikey**
- سجّل دخول بجوجل → **Create API Key** → انسخ المفتاح
- ⚠️ هذا مفتاح **مدفوع** (~0.02$–0.04$ لكل صورة يطلبها أي زائر يختار "جودة عالية") — لا تضيفه إلا لو قابل تتحمّل هالتكلفة. بدونه، خيار "جودة عالية" يبقى ظاهر بس يرد برسالة "غير مفعّل حالياً" تلقائياً.

## الخطوة 4: أنشئ مشروع Vercel جديد وأضف المفاتيح

1. روح لـ 🔗 **https://vercel.com/new**
2. اضغط **Import** بجانب مستودع `nextra-ai`
3. **قبل ما تضغط Deploy**، افتح قسم **Environment Variables** وأضف المفاتيح (اسم المتغير = القيمة):

| Key | Value | إجباري؟ |
|---|---|---|
| `GROQ_API_KEY` | المفتاح من console.groq.com | ✅ إجباري |
| `NVIDIA_API_KEY` | المفتاح من build.nvidia.com | ✅ إجباري |
| `UPSTASH_REDIS_REST_URL` | من console.upstash.com | ✅ إجباري |
| `UPSTASH_REDIS_REST_TOKEN` | من console.upstash.com | ✅ إجباري |
| `GEMINI_API_KEY` | من aistudio.google.com/apikey | ⭕ اختياري (صور مدفوعة) |

4. تأكد كلهم مفعّلين على **Production** (وممكن كمان Preview لو تحب)
5. اضغط **Deploy** واستنى دقيقة

بعد النشر، بيعطيك Vercel رابط مثل `https://nextra-ai-xxxx.vercel.app` — هذا رابط موقعك.

## الخطوة 5: تسجيل الدخول (Gmail) — اختياري

لو تبي تفعّل زر "تسجيل الدخول" (Gmail):
1. 🔗 **https://console.firebase.google.com** → **Add project** → أكمل الإنشاء
2. اضغط أيقونة **`</>`** (Web) → سمّه أي اسم → **Register app**
3. انسخ الست قيم من `firebaseConfig` اللي يطلع لك
4. افتح `index.html` بمستودعك على GitHub، دوّر على `const firebaseConfig = {`، والصق القيم بدل الفراغات
5. من Firebase: **Authentication → Get started → Sign-in method → Google → Enable**

⚠️ دخول الهاتف (SMS) يحتاج خطة Blaze المدفوعة بـ Firebase — لا ننصح تفعّله إلا بعد ما يصير عندك دخل حقيقي من الاشتراكات.

## المميزات الجاهزة بالمشروع

- 💬 محادثة نصية ثنائية اللغة (عربي/إنجليزي) مع احتياط تلقائي بين Groq وNVIDIA
- 🎯 3 تخصصات: عام / برمجة / تحليل — كل وحد بأفضل نموذج مجاني لمهمته
- 🎙️ صوت: تسجيل وتحويل لنص + استماع للردود
- 📸 رفع صور وفهمها (Vision) + توليد صور مع تحميلها
- 💬 محادثات متعددة (زي ChatGPT) — قائمة جانبية، محادثة جديدة، حذف
- 🖼️ حد 3 صور مجانية بالساعة (عبر Upstash)
- 📱 قابل للتثبيت كتطبيق على أندرويد وآيفون (PWA) + بانر تثبيت تلقائي بأعلى الصفحة
- 💎 خيار "جودة عالية" مدفوع لتوليد الصور عبر Gemini (اختياري، جنب الوضع المجاني)
- 💳 قسم أسعار (2.99$/شهرياً) مع دفع عبر واتساب
- 🔐 تسجيل دخول Gmail (يحتاج ربط Firebase حسب الخطوة 5)
- 🏷️ هوية "Nextra AI" ثابتة بكل الردود — أي سؤال عن الهوية يرد برد ثابت محدد
- 🛡️ حماية 3 طبقات ضد تسريب "تفكير" النموذج الداخلي (`<think>`) بالردود

## نظام الاحتياط التلقائي

كل رسالة تمر بترتيب مزوّدين حسب التخصص المختار (لو الأول تعطّل، يجرب الثاني تلقائياً بدون ما يحس المستخدم بانقطاع):
- **عام:** Groq (`qwen/qwen3.6-27b`) ← NVIDIA (`deepseek-ai/deepseek-v4-flash`)
- **برمجة:** NVIDIA (`deepseek-ai/deepseek-v4-flash`) ← Groq (`qwen/qwen3.6-27b`)
- **تحليل:** NVIDIA (`mistralai/mistral-large-3-675b-instruct-2512`) ← Groq (`qwen/qwen3.6-27b`)

⚠️ **ملاحظة مهمة:** نماذج Groq وNVIDIA تتغيّر بمرور الوقت (توقفوا نماذج قديمة بشكل دوري). لو رجع لك خطأ "خطأ من مزوّد النموذج" مستقبلاً، شوف حقل `debug.lastProviderMessage` بالرد — لو فيه عبارة "end of life" أو "no longer available"، يعني النموذج نفسه احتاج تحديث لاسم أحدث (راجع console.groq.com/docs/models أو build.nvidia.com للاسم الجديد).

## استكشاف الأخطاء

لو ظهر خطأ "خطأ من مزوّد النموذج"، الرد نفسه (JSON) فيه معلومات تشخيصية حقيقية (`debug`) توضح بالضبط أي مفتاح فاشل ورمز الخطأ الحقيقي — تقدر تشوفها بأدوات المطور بالمتصفح (F12 → Network) أو بـ Vercel → Deployments → آخر نشر → Runtime Logs.
